Анализатор логов Majestic: приложение для Windows

Запуск: откройте "Majestic Log Advisor.exe". Установка не нужна.
Папку можно положить куда угодно (например C:\Tools\Majestic Log Advisor).
Ярлык на рабочий стол: правая кнопка на .exe -> Отправить -> Рабочий стол (создать ярлык).

Windows может показать предупреждение SmartScreen, потому что программа без цифровой подписи:
нажмите "Подробнее" -> "Выполнить в любом случае".

Что умеет:
- "Логи с этого ПК": находит main.log и client.log лаунчера в %APPDATA%\majestic-launcher и загружает в один клик.
- "Добавить папку", перетаскивание папок и zip-архивов с логами.
- Моды в папке игры определяются по самим логам и всегда выводятся на первое место.
- "Ответ игроку": готовый текст с шагами, можно править и копировать.
- "Добавить решение" у неопознанной строки: ваше правило применяется ко всем логам.
- Вкладки "Сравнение", "История" (по нику или тикету), "Сводка".
- Отчёт в PDF и HTML.
- "Обновление": интерфейс обновляется сам при запуске из репозитория на GitHub; вручную можно из файла .html.

База знаний (метки, заметки, правила, история) хранится в профиле приложения
(%APPDATA%\majestic-log-advisor) и не зависит от папки программы.
Обмен с коллегами: вкладка "Обучение" -> "Экспорт базы знаний" и "Слить с чужой базой".

Логи читаются на вашем компьютере и никуда не отправляются.
Для вопросов к Claude используйте кнопки "Скопировать для Claude" и вставьте текст в чат.
