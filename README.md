## Установка

1. Нажмите **«Скачать для Windows»** выше и запустите установщик.
2. При первом запуске приложение покажет **код компьютера**. Отправьте его администратору: после выдачи доступа программа заработает.
3. Дальше приложение обновляется само, тихо, при следующем запуске.

> Установщик без цифровой подписи, поэтому SmartScreen может предупредить: «Подробнее» → «Выполнить в любом случае».

## Что умеет

- **Диагноз по логу.** `main.log`, `client.log`, `launcher.log`, патчер, zip или папка: причина, шаги по руководству и готовый ответ игроку.
- **Дамп и журнал Windows.** `.dmp`, `.evtx`, zip краш-отчёта: модуль и код сбоя, события рядом с падением, известные причины по версии клиента.
- **Просмотр лога.** Подсветка, поиск (`a | b`, `-слово`), свёртка повторов, шаблоны строк, ошибки по минутам, окно ±30 с, фрагмент для тикета.
- **Дела и очередь.** Логи одного игрока в папке-деле, активные и отложенные, статусы, история, отчёты HTML и PDF.
- **Команда.** Общая база тикетов, массовые проблемы, ответы и заметки коллег, общие правила и известные причины сбоев.
- **Плагин Discord** «В анализатор»: файлы и данные игрока из ваших тикетов сразу попадают в программу.
- **ИИ-разбор** по кнопке, если на сервере подключён ИИ.

Подробно о каждой версии — в окне «Что нового» в приложении.

## Для саппорта

1. Перетащите логи в окно. «Диагноз» называет причину, «Ответ игроку» даёт текст, «Отчёт» собирает данные для тикета.
2. Краш без кода `ERR_`: добавьте `.dmp` или журнал Windows в карточке «Дамп краша и журнал Windows».
3. Что попросить у игрока — в меню «Ещё» → «Инструкция».

## Плагин Discord

1. Скачайте [Majestic-Plugin-Installer.exe](https://github.com/persephonemajestic/majestic-log-advisor/releases/download/plugins-installer/Majestic-Plugin-Installer.exe), запустите и выберите Vencord или BetterDiscord. Ваши другие плагины остаются на месте.
2. В программе: «Настройки» → «Плагин Discord» → «Скопировать ключ», вставьте ключ в настройки плагина в Discord.
3. В тикете у файла лога появится кнопка «В анализатор». Повторный запуск установщика обновляет плагины.

## Конфиденциальность

Логи разбираются на вашем компьютере, почта, IP, имя пользователя Windows, токены и пароли маскируются. Если включено «Улучшение правил» (по умолчанию), на сервер команды уходит очищенная копия лога с маской личных данных, она хранится 7 дней и раз в сутки прогоняется по правилам. Выключается в «Настройках».
