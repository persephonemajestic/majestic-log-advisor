## Установка

1. Нажмите **«Скачать для Windows»** выше и запустите установщик.
2. При первом запуске нажмите **«Регистрация»**, придумайте логин и пароль (от 8 символов, буквы и цифры). Администратор выдаст доступ, и программа откроется сама. Тот же логин подходит для телефона.
3. Дальше приложение обновляется само: новая версия скачивается в фоне и ставится, когда вы не работаете в окне, с возвратом на тот же лог и вкладку.

> Установщик без цифровой подписи, поэтому SmartScreen может предупредить: «Подробнее» → «Выполнить в любом случае».

## На телефоне (iPhone и Android)

1. Откройте в Safari или Chrome: **https://majestic-log-advisor.requesteadm.workers.dev/m/**
2. Войдите тем же логином и паролем, что и на компьютере (или зарегистрируйтесь — тогда администратор выдаст доступ).
3. iPhone: «Поделиться» → «На экран „Домой“». Android: меню браузера → «Установить приложение». Анализатор откроется как обычное приложение.
4. Логи из Discord: на iPhone — открыть файл → «Поделиться» → «Сохранить в Файлы», затем «+» в анализаторе. На Android можно сразу «Поделиться» → «Логи Majestic».

Логи разбираются на самом телефоне. Плагина Discord на телефоне нет: файл добавляется кнопкой «+».

## Что умеет

- **Диагноз по логу.** `main.log`, `client.log`, `launcher.log`, патчер, zip или папка: причина, шаги по руководству и готовый ответ игроку.
- **Дамп и журнал Windows.** `.dmp`, `.evtx`, zip краш-отчёта: модуль и код сбоя, события рядом с падением, известные причины по версии клиента.
- **Просмотр лога.** Подсветка, поиск (`a | b`, `-слово`), свёртка повторов, шаблоны строк, ошибки по минутам, окно ±30 с, фрагмент для тикета. Логи на сотни мегабайт открываются без замирания окна.
- **Панель логов как проводник.** Свои папки (кнопка «Папка»), перетаскивание логов, поиск, «В работе» и «Архив».
- **Дела и очередь.** Логи одного игрока в папке-деле, ответ игроку по всему делу, сравнение «до и после», прошлые тикеты игрока, статусы, отчёты HTML и PDF.
- **Команда.** Общая база тикетов, массовые проблемы, ответы и заметки коллег, общие правила и известные причины сбоев.
- **Плагин Discord.** «Разбор» у логов и скриншотов прямо в тикете: причина, как чинить и готовый ответ игроку, который вставляется в чат одной кнопкой; значки с итогом рядом с логами; `Ctrl+Shift+L` — разбор последнего лога тикета; готовые шаблоны ответов команды по тексту игрока, скриншоту или логу. «В анализатор»: один файл или все файлы тикета вместе с данными игрока сразу попадают в программу.
- **Клавиши.** `?` — все сочетания, `/` — поиск, `1–9` — вкладки, `R` — скопировать ответ игроку.
- **ИИ-разбор** по кнопке, если на сервере подключён ИИ.

Подробно о каждой версии — в окне «Что нового» в приложении.

## Для саппорта

1. Перетащите логи в окно. «Диагноз» называет причину, «Ответ игроку» даёт текст, «Отчёт» собирает данные для тикета.
2. Краш без кода `ERR_`: добавьте `.dmp` или журнал Windows в карточке «Дамп краша и журнал Windows».
3. Что попросить у игрока — в меню «Ещё» → «Инструкция».

## Плагин Discord

1. Скачайте [Majestic-Plugin-Installer.exe](https://github.com/persephonemajestic/majestic-log-advisor/releases/download/plugins-installer/Majestic-Plugin-Installer.exe), запустите и выберите Vencord или BetterDiscord. Ваши другие плагины остаются на месте.
2. В программе: «Настройки» → «Плагин Discord» → «Скопировать ключ», вставьте ключ в настройки плагина в Discord.
3. В тикете у файла лога появятся кнопки «Разбор» и «В анализатор», у скриншота — «Разбор скриншота», у первого файла ветки — «Все файлы тикета». `Ctrl+Shift+L` — разбор последнего лога открытого тикета.
4. Обновления: в установщике пункт «Автообновление при входе в Windows»; версия для BetterDiscord обновляется и сама.

## Конфиденциальность

Логи разбираются на вашем компьютере. Если включено «Улучшение правил» (по умолчанию), на сервер команды уходит очищенная копия лога с маской личных данных, она хранится 7 дней и раз в сутки прогоняется по правилам. Выключается в «Настройках». «Разбор скриншота» отправляет скриншот на распознавание ИИ через сервер команды (только по нажатию кнопки, скриншот не сохраняется); чёрные полосы ищутся на вашем компьютере.
